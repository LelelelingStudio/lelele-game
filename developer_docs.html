📚 了了了游开发者文档

版本 1.0.0 · 最后更新：2026 年 10 月 23 日 📌 适用于所有入驻开发者
🚀
欢迎加入我们：本指南将带您了解如何注册成为开发者、如何使用开发者后台（Dashboard）、以及如何提交您的游戏代码。在注册和使用前，请务必阅读并遵守 《了了了游游戏守则》。

第一章 成为开发者

1.1 注册账号

点击首页右上角的“投稿”按钮，或直接访问 login.html。选择“注册”，输入您的邮箱和密码。系统将向您的邮箱发送一封包含 8 位验证码的邮件，输入验证码即可完成注册。注册后，您将自动获得一个开发者后台账号。

1.2 开发者规则与规范

  • 合规经营：您提交的所有游戏必须遵守当地法律法规，且符合《游戏守则》中的内容规范（严禁色情、暴力、赌博等内容）。
  • 原创与版权：您必须保证对提交的游戏拥有完整版权，或已获得充分授权。严禁抄袭、盗用他人作品。
  • 禁止恶意代码：游戏代码中严禁包含任何恶意脚本、挖矿程序、后门程序或试图窃取用户隐私数据的代码。

1.3 开发者与隐私

了了了游非常重视您的隐私。您上传的头像、简介仅用于在平台公开展示。您在后台看到的“游玩量”和“收藏量”数据为匿名聚合数据，我们不会将具体的玩家个人数据泄露给您。同时，您也不得在游戏中违规收集玩家的个人信息。

第二章 开发者后台 (Dashboard) 指南

登录后点击右上角您的头像，即可进入开发者后台。后台包含以下核心功能：

2.1 数据看板 (Analytics)

  • 折线图：直观展示您的游戏在过去 1天/7天/30天/90天/1年内的“游玩量”与“收藏量”。
  • 环比趋势：系统会自动对比上一个周期，为您展示增长或下降的幅度。为了增添趣味性，我们使用了 Emoji 和文字提示（详见下方对照表）。
趋势状态变化幅度Emoji 提示
原地踏步0%🛌 数据持平，继续努力
缓慢增长+1% ~ +20%🌱 您的游戏正在缓慢增长中...
快速上升+21% ~ +60%🎢 数据快速上升，势头不错！
火爆全站+60% 以上🚀 火爆全站！玩家非常喜欢！

2.2 个人资料设置

  • 修改信息：您可以随时修改您的“显示名称”和“个人简介”。这些信息将同步显示在您所有游戏的详情页和公开作者主页中。
  • 上传头像：支持 JPG/PNG 格式。为了网页加载速度，系统会自动将图片压缩至 50KB 以内并上传。

2.3 账号设置与注销

您可以在这里发送重置密码的邮件。如果您决定离开平台，可以点击“注销账号”。注意：注销将永久删除您的账号、资料及绑定的游戏所有权记录，此操作不可逆。系统会要求您输入“DELETE”进行二次确认。

第三章 游戏接入与提交流程

3.1 技术规范

  • 仅支持纯前端代码（HTML / CSS / JavaScript / JSON）。
  • 不能包含任何后端代码（如 Node.js, PHP, Python）或依赖本地数据库。
  • 必须在静态托管环境下直接打开即可运行，不能有需要编译的框架源码。

3.2 投稿流程

  1. 在首页点击“投稿”按钮，阅读并勾选《投稿须知》。
  2. 阅读并勾选《授权确认》，授予平台非独占展示权。
  3. 填写弹出的 Tally 表单（包含游戏名称、分类、代码上传/链接等信息）。
  4. 审核周期为 5 个工作日，无论通过与否，我们都会通过邮件通知您。

第四章 常见问题 (FAQ)

Q: 为什么我在后台看不到我的游戏？

A: 请检查您填写的“显示名称”是否与 `lelegame_data.json` 中的 `author` 字段完全一致（区分大小写与空格）。

Q: 数据看板的数据多久更新一次？

A: 您的数据会实时更新，图表默认展示近 30 天的趋势。

Q: 我该怎么下架游戏？

A: 您可以在后台注销账号，或者发送邮件至 leleleling@2980.com 申请下架特定游戏。下架后 30 天内，我们将停止对该游戏的新增使用。

📚 lelele Game Developer Docs

Version 1.0.0 · Last updated: October 23, 2026 📌 For all registered developers
🚀
Welcome aboard: This guide will walk you through registering as a developer, using the Dashboard, and submitting your game code. Before registering, please read and comply with the lelele Game Rules.

Chapter 1 Becoming a Developer

1.1 Registering an Account

Click the "Submit" button on the top right of the homepage, or visit login.html. Select "Register" and enter your email and password. The system will send an email with an 8-digit verification code. Enter the code to complete registration and get your Dashboard account.

1.2 Developer Rules

  • Compliance: All submitted games must comply with local laws and the content guidelines in the Game Rules (no porn, violence, or gambling).
  • Originality: You must own the copyright or have full authorization for your submitted game. Plagiarism is strictly prohibited.
  • No Malicious Code: Games must not contain malicious scripts, mining programs, backdoors, or code that steals user privacy.

1.3 Developer & Privacy

We value your privacy. Your uploaded avatar and bio are only used for public display. The "Plays" and "Favorites" data you see in the Dashboard is anonymous aggregate data; we do not leak specific user data to you. Likewise, you must not improperly collect player personal information in your games.

Chapter 2 Dashboard Guide

After logging in, click your avatar in the top right to enter the Dashboard. Core features include:

2.1 Analytics

  • Line Chart: Visually displays your game's "Plays" and "Favorites" over the past 1/7/30/90 days or 1 year.
  • Trend Indicator: The system compares with the previous period. We use Emojis and text for a fun experience (see table below).
StatusChangeEmoji Prompt
Flat0%🛌 Staying flat, keep it up
Slow Growth+1% ~ +20%🌱 Slowly growing...
Fast Growth+21% ~ +60%🎢 Rising fast! Good momentum.
Booming+60%+🚀 Trending! Players love it.
Slight Dip-1% ~ -20%🍂 Slight dip, normal fluctuation.
Sliding-21% ~ -60%🛹 Sliding down, maybe do some promotion.
Landing-60%+🪂 Landing... take a rest and wait for a bounce.

2.2 Profile Settings

  • Edit Info: You can change your "Display Name" and "Bio" anytime. This info syncs to your game detail pages and public author page.
  • Upload Avatar: Supports JPG/PNG. To speed up loading, images are automatically compressed to under 50KB before upload.

2.3 Account Settings & Deletion

You can request a password reset email here. If you decide to leave, you can "Delete Account". Note: Deletion permanently removes your account, profile, and game ownership records. This is irreversible. You will be asked to type "DELETE" to confirm.

Chapter 3 Game Submission

3.1 Tech Specs

  • Only pure front-end code is supported (HTML / CSS / JavaScript / JSON).
  • No backend code (Node.js, PHP, Python) or local databases.
  • Must run directly in a static hosting environment. No source code requiring a build step.

3.2 Submission Process

  1. Click "Submit" on the homepage and agree to the Submission Guidelines.
  2. Agree to the License Confirmation (granting us non-exclusive display rights).
  3. Fill out the Tally form (game name, category, code upload/link, etc.).
  4. Review takes 5 business days. We will notify you by email whether it passes or not.

Chapter 4 FAQ

Q: Why can't I see my game in the Dashboard?

A: Please check if your "Display Name" exactly matches the `author` field in `lelegame_data.json` (case and space sensitive).

Q: How often does the Dashboard data update?

A: Data updates in real-time. The chart shows the last 30 days by default.

Q: How do I take down my game?

A: You can delete your account in the Dashboard, or email leleleling@2980.com to request removal of a specific game. We will cease new use of the game within 30 days of removal.
