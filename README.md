## 这是什么？

**了了了游** 是了了了岭工作室旗下的 **HTML5 小游戏平台**。

不用下载、不用安装，打开网页就能玩——**工作间隙摸个鱼，刚刚好**。

---

## 规划方向

- 🎮 聚合精选 HTML5 小游戏
- 🏆 支持分数记录与排行
- 📱 手机 / 电脑全适配，触屏 + 键鼠都支持
- 🌙 暗色模式，深夜摸鱼不刺眼

> ⚠️ 产品仍在规划中，具体功能以上线版本为准。

---

## 技术栈

- 前端：纯 HTML + CSS + JavaScript（零框架）
- 游戏引擎：原生 Canvas / WebGL
- 部署：GitHub Pages + Cloudflare 加速
