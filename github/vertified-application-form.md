# 开发者「官方认证（Vertified）」申请表单 — Tally 规格

> 用途：交给 Tally（https://tally.so）按此规格搭建 **「开发者申请官方认证 / vertified」** 表单。
> 申请通过后，由站长在 **admin 控制台「🛠 修改作者信息」** 选该作者 id，勾选 `official`（及调整 `authorlevel`）后提交；数据写入本仓库 `authors/index.json`（唯一权威源）。默认开草稿 PR，合并后生效。⚠️ `authors.surge.sh` 已于 2026-11-14 退役，不要再改站外文件。

---

- **表单标题（英文）**：lelele Game · Developer Verified Application

- **提交后跳转**：`https://game.leleleling.site/about.html`（可选）
- **接收邮箱（通知）**：`leleleling@2980.com`
- **开启**：防垃圾（reCAPTCHA / 限频）、必填校验、邮箱格式校验。

## 4. 必须勾选的条款（Checkbox 文案）

- [ ] 我已阅读并同意《创作者认证规则》（链接见下）
- [ ] 我承诺所提交内容真实、合规，不含有侵权 / 违规内容
- [ ] 我理解官方认证由人工审核，结果以邮件通知为准

> Tally 中把「同意条款」设为 **Required**，未勾选禁止提交。

## 5. 认证等级规则（展示给申请者，链接到规则页）

在表单说明区放一段文字 + 链接，说明各级要求（与 `AUTHOR_CERTIFICATION.md` 保持一致）：

- **制作人**：已发布 ≥1 款游戏；资料完整；至少绑定一种登录方式。
- **优质制作人**：累计发布 ≥3 款；至少 1 款上架 ≥14 天且无严重违规；或被官方编辑推荐。
- **开发者**：累计发布 ≥3 款且至少 1 款上架 ≥30 天；通过内容合规复审；收到 ≥10 条有效玩家反馈。
- **金牌开发者**：累计发布 ≥5 款；至少 2 款评分 ≥4.7 或总游玩 ≥10 万；无违规；经官方评定。
- **开发团队**：以团队名义注册并绑定组织；≥5 款游戏；官方认证的组织实体；支持多人协作。

**规则页链接**：`https://game.leleleling.site/AUTHOR_CERTIFICATION.html`（或 about 内嵌章节）
**行为准则链接**：`https://game.leleleling.site/about.html`
**联系/申诉**：`leleleling@2980.com`

## 6. 条件逻辑（Tally Logic）

- 当 `申请认证等级 == 开发团队` → 显示并强制填写 `组织名称` 与 `官网 / 社交主页`。
- 当 `申请认证等级 == 普通创作者` → 不允许提交（该等级无需申请，注册即获得）；可设为隐藏或提示「无需申请」。

## 7. 提交后处理（后台）

1. Tally 通知邮件 → 站长核对 `作者 ID` 与本仓库 `authors/index.json`。
2. 审核通过 → 在 **admin 控制台「🛠 修改作者信息」** 选该 id，勾选 `official`、必要时调整 `authorlevel`，提交并**合并草稿 PR**（或勾选「直接推送 main」）。数据写入 `authors/index.json`，Pages 发布后生效。⚠️ 不再编辑站外 `authors.json` / 部署 Surge。
3. 审核不通过 → 邮件说明原因，可重新申请。
4. 可另用「🔔 发开发者专用告示」按作者 id 推送认证结果通知。

## 8. 注意

- 本表单只负责「申请收集」，最终认证状态以本仓库 `authors/index.json` 数据为准（唯一权威源，见 `foraisthings.md` 3.4）。
- 「官方」标识渲染：中文【官方】/ 英文 Official（红徽章）；「本站原创团队」仅主理团队（`studio_special`）使用，不对申请者开放。
